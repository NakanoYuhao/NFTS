结构概要：
模块	文件数	说明
API Routes	12	AI 生成 (4) + NFT (6) + 存储 (5) + 上传 (1)
页面组件	11	首页 / 创作 / 藏品柜 / 详情 / 对话 / NFT 申请等
shadcn/ui	55	完整预装组件库
Hooks	3	状态管理、链上同步、移动端检测
Lib	13	Web3 / 合约 / 索引器 / IPFS / 存储 / 提示词等
合约	1	ERC-721 OpenNFT
脚本	6	构建 / 启动 / 部署 / 校验
项目采用 Next.js App Router 全栈架构，前端通过 SPA 状态管理模拟多页面切换，后端 API Routes 提供 AI 生成、NFT 铸造、存储等服务。Web3 层通过 Wagmi + RainbowKit 连接钱包，平台钱包代付 Gas 铸造 NFT 到用户地址，元数据通过 Pinata 上传 IPFS。
