============================================================
  手动启动步骤（如果 resume.ps1 无法使用）
============================================================

以下按顺序在 4 个终端窗口中操作。

------------------------------------------------------------
终端 1：启动 Hardhat 本地区块链
------------------------------------------------------------

  cd contracts
  npx hardhat node

  等待输出 "Started HTTP and WebSocket JSON-RPC server"
  保持此窗口不关闭！

------------------------------------------------------------
终端 2：部署合约 + 链上认证
------------------------------------------------------------

  cd contracts
  npx hardhat run script/deploy.ts --network localhost
  npx hardhat run verify-all.ts --network localhost

  合约部署后会输出 7 个合约地址。
  如果 .env 中的地址与输出不一致，手动更新 backend\.env。

------------------------------------------------------------
终端 3：启动后端 API
------------------------------------------------------------

  cd backend

  （首次需要：npm install && npx prisma generate && npx prisma migrate dev --name init）

  npx nest build
  node dist/main.js

  等待输出 "[NFC Guard] Server running on http://localhost:8080"
  保持此窗口不关闭！

  （另开终端，可选）修复数据库认证状态：
  cd backend
  node fix-db.js

------------------------------------------------------------
终端 4：启动前端
------------------------------------------------------------

  cd frontend

  （首次需要：npm install）

  npm run dev

  等待输出 "Local: http://localhost:5173"
  保持此窗口不关闭！

------------------------------------------------------------
可选：启动 Docker 服务（IPFS + Redis）
------------------------------------------------------------

  cd docker
  docker-compose up -d postgres redis ipfs

  如果 Docker 不可用，项目自动使用本地存储降级。

------------------------------------------------------------
可选：运行完整业务流程演示（终端脚本，不需要 MetaMask）
------------------------------------------------------------

  cd contracts
  npx hardhat run demo.ts

  输出 7/7 步全部通过即为正常。

------------------------------------------------------------
验证
------------------------------------------------------------

  浏览器打开 http://localhost:5173
  按 MetaMask配置指南.txt 配置钱包后登录。
