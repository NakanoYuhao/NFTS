● 项目结构总结：OPEN-NFTs

  这是一个基于 Next.js 16 (App Router) + shadcn/ui + Tailwind CSS
  v4 的全栈 NFT 潮玩创作平台，使用 pnpm 管理依赖。

  ---
  目录结构

  projects/
  ├── contracts/OpenNFT.sol           # 极简 ERC-721 智能合约
  ├── scripts/                        # 构建/启动/部署脚本
  (build.sh, dev.sh等)
  ├── public/                         # 静态资源 (SVG图标)
  ├── .cozeproj/                      # 扣子编程平台配置 (design
  doc, prototype)
  ├── src/

  ---
  核心业务流程

  1. 潮玩创作：拍照模式 (CreatePage photo) 或自由创作模式
  (CreatePage free)，通过 AI (generate-content/generate-free)
  生成潮玩的人格、故事、性格、外观等
  2. .onft v4 打包：人格锚点 (persona) + Agentic Protocol
  (personaProtocol) + 图片 → 打包为 .onft
  二进制文件，生成独立的身份 JSON
  3. AI 对话：基于人格蒸馏（女娲五层结构）的对话系统，藏品可作为 AI
   角色与用户聊天
  4. NFT 铸造：上传 .onft 到 IPFS (Pinata) → 生成 metadata → 调用
  OpenNFT.sol 合约 safeMint 铸造 ERC-721
  5. 链上同步：通过 Alchemy/合约索引器同步链上 .onft 格式 NFT
  到本地藏品柜

  ├────────┼───────────────────────────────────────────────────┤
  │ 验证   │ Zod v4 + React Hook Form                          │
  ├────────┼───────────────────────────────────────────────────┤

  └────────┴───────────────────────────────────────────────────┘
