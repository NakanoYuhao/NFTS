============================================================
  复现人员操作清单 —— 必须人工完成的步骤
============================================================

以下步骤无法自动化，需要复现人员手动操作：

------------------------------------------------------------
一、软件安装（一次性）
------------------------------------------------------------

  [ ] 安装 Node.js 20+
      下载：https://nodejs.org
      验证：node --version

  [ ] 安装 pnpm
      命令：npm install -g pnpm
      验证：pnpm --version

  [ ] 安装 PostgreSQL 16
      下载：https://www.postgresql.org/download/
      安装后创建数据库 nfc_registry
      或使用 Docker：docker run -d --name pg -p 5432:5432 -e POSTGRES_DB=nfc_registry postgres:16

  [ ] 安装 MetaMask 浏览器插件
      下载：https://metamask.io
      支持 Chrome / Firefox / Edge

  [ ] （可选）安装 Docker Desktop
      下载：https://www.docker.com/products/docker-desktop
      提供 IPFS + Redis

  [ ] （可选）安装 Git Bash
      下载：https://git-scm.com
      使 OPEN-NFTs 的 bash 脚本可在 Windows 上运行

------------------------------------------------------------
二、首次配置（一次性）
------------------------------------------------------------

  [ ] 复制环境变量
      copy 二创监管平台\backend\.env.example 二创监管平台\backend\.env
      （如需修改数据库连接，编辑 .env）

  [ ] 创建数据库
      PostgreSQL 中执行：CREATE DATABASE nfc_registry;

  [ ] 安装所有依赖（约 5-8 分钟）
      cd 二创监管平台\contracts && npm install && cd ..\..
      cd 二创监管平台\backend && npm install && cd ..\..
      cd 二创监管平台\frontend && npm install && cd ..\..
      cd OPEN-NFTs\projects && pnpm install && cd ..\..

  [ ] 初始化数据库表
      cd 二创监管平台\backend
      npx prisma generate
      npx prisma migrate dev --name init
      cd ..\..

------------------------------------------------------------
三、每次启动（需保持 4 个终端窗口）
------------------------------------------------------------

  终端 1（Hardhat）：
      cd 二创监管平台\contracts
      npx hardhat node

  终端 2（部署 + 后端）：
      cd 二创监管平台\contracts
      npx hardhat run script/deploy.ts --network localhost
      npx hardhat run verify-all.ts --network localhost
      cd ..\backend
      npx nest build
      node dist/main.js
      node fix-db.js

  终端 3（前端）：
      cd 二创监管平台\frontend
      npm run dev

  终端 4（OPEN-NFTs）：
      cd OPEN-NFTs\projects
      $env:PORT=5000
      pnpm tsx watch src/server.ts
      （如有 Git Bash：bash ./scripts/dev.sh）

  或使用一键脚本：
      powershell -ExecutionPolicy Bypass -File "二创监管平台\resume.ps1"
      （自动完成终端 1-3，终端 4 需要单独操作）

------------------------------------------------------------
四、MetaMask 配置（一次性）
------------------------------------------------------------

  [ ] 添加 Hardhat 网络
      MetaMask → 设置 → 网络 → 手动添加
      网络名称：NFC Trendy Guard Local
      RPC URL：http://127.0.0.1:8545
      链 ID：1337
      货币符号：ETH

  [ ] 导入测试账户
      MetaMask → 导入账户 → 粘贴私钥
      Admin (Account #0): 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
      Creator (Account #1): 0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d

------------------------------------------------------------
五、浏览器验证
------------------------------------------------------------

  [ ] 打开 http://localhost:5173（二创平台）
      → 连接 MetaMask → 签名登录 → 仪表盘

  [ ] 打开 http://localhost:5000（OPEN-NFTs）
      → 创作者模式 → 创作潮玩 → 铸造 NFT → 登记为二创原作

  [ ] OPEN-NFTs → 企业模式
      → 点击任意卡片 → 应在新标签页打开二创平台对应页面
